# 1.0.0+korboy8

- Preserve the caller's native accessibility context during setup. Remove two manual client lookups that do not resolve on the supplied iOS releases; the existing automation switches remain responsible for enabling inspection.
- Reject incompatible lock-screen factory and unlock argument types before preparing the passcode or invoking the native unlock method.

Validation: native signature fixtures, both unlock RPC variants and ten RPC
failure/cleanup modes passed on the Mac. A phone probe confirmed that
accessibility setup preserves the existing client context. Binary and package
verification passed for both architectures and all three iOS layouts.

The installed iOS 17.1.1 build passed 68 acceptance cases before phone testing
was paused at the user's request. The 110-case non-reboot run is incomplete;
no other iOS version was tested on hardware.
