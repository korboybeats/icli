# 1.0.0+korboy14

- `input type --clear` and `input paste --clear` work with `--parallel`: the
  session's app empties the focused field before inserting (needs
  `com.korboy.parallel` with clear support). Before, `--clear` was refused.
- With Parallel's update, typing right after the tap that focuses a field no
  longer fails with `no_focused_text_input` while the field is still taking
  focus: the app waits up to 2 seconds for it.

Tested on an iPhone 15 Pro Max with iOS 17.1.1 (rootless): three Parallel
sessions (two fixture apps and Settings) each tapped a text field and
immediately ran `input type <word> --clear`, five rounds at the same time. Every
field held only its own round's word, read back by OCR; the first round in
Settings' search field, which animates in after the tap, succeeded too.
