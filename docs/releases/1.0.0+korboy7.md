# 1.0.0+korboy7

- Use iOS 14's native rotation actions and foreground-process predicate when the newer APIs are absent.
- Preserve signer information when registering rootful apps on iOS 14, use the older registration API on iOS 14–15, and initialize LaunchServices for standalone app lookups.
- Read Silent mode on iOS 14–16 through the native accessibility service, preserving unavailable replies. Native writes remain available from iOS 17 on supported devices.
- Decode process logs using the measured iOS 14–16, 17–18 and 26–27 layouts, including packed timestamps on iOS 26–27.
