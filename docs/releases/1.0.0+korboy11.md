# 1.0.0+korboy11

- Enable native location simulation set/clear requests on iOS 14. Set reads
  fresh matching coordinates back. Both commands return `simulating: null`
  there because iOS 14 cannot confirm simulation provenance or stop completion.
  Clear waits for the native send barrier before the process exits.
- Reject mismatched location readback even when its simulated flag is true.
  Failed readback sends the existing stop/clear cleanup request.

Twenty-five Mac host checks passed against production request, delivery and
JSON-decoding logic, covering older/newer results, readback mismatches, cleanup,
native errors, connection signatures, send completion and input validation.
Both CPU architectures and all three iOS package layouts
passed binary/package verification. iOS 14 device operation has not been tested.
