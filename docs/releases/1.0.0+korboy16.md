# 1.0.0+korboy16

- `icli parallel create --screen n` opens the app in an existing Parallel Space
  instead of a new one.
- `icli parallel attach <session>` takes control of an app the person opened in
  a Space and prints its token; `--export` prints shell assignments as with
  `create`.

These replace the `parallel` tool that Parallel used to ship; icli is now its
only client.
