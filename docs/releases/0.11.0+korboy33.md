Everything this fork adds to upstream icli 0.11.0. Fork versions are upstream's version plus `+korboyN`, so they never take a number upstream releases.

**Control Center**
- `icli cc list | get | set | toggle` reads and sets `airplane`, `wifi`, `bluetooth`, `cellular`, `hotspot`, `airdrop` (`off`, `contacts`, `everyone`; Everyone turns itself off after 10 minutes), `focus` (`on` for Do Not Disturb, `off`, or a Focus name such as `sleep` or `work`), `flashlight` (`on`, `off` or a level from 0 to 1), `rotation-lock`, `low-power` and `appearance` (`light`, `dark`). `mirroring` is read-only: it reports whether the screen is mirrored and to which device. Every command answers with the state read back after the change, and `changed` says whether it moved. A change shows in Control Center and Settings and stays after icli exits; a Focus turned on by icli stays on as one turned on in Control Center does.
- The CLI signing profile adds the entitlements this needs: `com.apple.SystemConfiguration.SCPreferences-write-access` (`com.apple.radios.plist`), `com.apple.wifi.manager-access`, `com.apple.bluetooth.system`, `com.apple.private.airdrop.settings`, `com.apple.avfoundation.allow-system-wide-context`, and four Do Not Disturb client-identifier keys. Each is described in docs/entitlements.md.

**Inspecting and scripting apps**
- `icli flex` brings FLEX's in-app inspection to the command line, ported from waruhachi's FlexUltra: all 102 tools for live objects, the heap, views and view controllers, the file system, defaults, keychain, SQLite and Realm databases, network history, the app's log and method tracing. The agent is loaded into the app only when a command runs; nothing stays running and no network port is opened. `icli flex network record on|off|status` switches FLEX's network recorder. On iOS 17 the app's log is read by icli's own recorder, because FLEX's reads every message as `<compose failure [corrupt log]>` there. A Realm file opens with the app's own schema version, so an app that set one is no longer refused with "Provided schema version 0 is less than last set version".
- `icli probe --app <bundle-id>` runs a probe script inside an app, on its main thread, through the agent `app launch --probe` loads. Probe values carry CGRect, CGPoint, CGSize, UIEdgeInsets and NSRange in both directions.

**Installing apps**
- `icli app install <file.ipa> --container` re-signs every Mach-O in the app ad-hoc before installing it, as TrollStore Lite does with ldid, inside icli: app and extension binaries keep their entitlements and get `jb.pmap_cs.custom_trust` = `PMAP_CS_APP_STORE`. Decrypted App Store and developer-signed IPAs now launch. A FairPlay-encrypted main binary is refused. `--keep-signature` installs the app as it is signed. The signature is the one `codesign -s -` makes (SHA-256 CodeDirectory, XML and DER entitlements); macOS `codesign --strict` accepts it.
- Container installs register the app as System by default (`--registration user` for User); FrontBoard refuses to launch an ad-hoc signed User app with "No code signature found". `app uninstall --force` also removes apps TrollStore installed.
- Reading an installed app's executable no longer kills icli when the kernel holds a signature for it that it rejects (SIGKILL CODESIGNING, "Invalid Page").

**UI automation**
- `ui tree` includes system UI (the Home Screen, Spotlight, alerts, Control Center, the app switcher) with `--scope auto|app|system|all` and `--source ax|ocr|any`, reads the app's and SpringBoard's trees at the same time, and takes `--hierarchy`. `ui tree`, `ui at`, the waits and `screen ocr` take `--compact` (one line per element, with trait names), also inside `batch` and `session`.
- `ui perform` taps an element and verifies what it changed. `ui tap` ranks matches (exact, enabled, tappable) and refuses ambiguous ones; `--index` keeps the old pick. `--expect`, `--expect-gone` and `--expect-timeout` on `screen tap`, `ui tap`, `ui fill`, `ui alert` and `ui back` wait for the result.
- New: `ui fill` (also at a point with `--x --y`), `ui alert`, which answers alerts and refuses passcode, Apple Account, payment and similar prompts, `ui prompt`, `ui back`, `input hide-keyboard`, and `input paste`/`type` with `--clear` and `--submit`.
- Waits are paced by screen frames: `ui wait`, `ui wait-gone`, `ui perform`, `--expect` and `screen wait` check again only after a new frame, at most once per `--interval` (0.1 s by default).
- Scrolling: `ui scroll-to` pages one scroll view through accessibility and reveals clipped rows. `screen scroll-by` and `screen swipe --no-momentum` stop without a fling and land within a point, also over many strokes: a stroke passes the scroll view's slop a pixel at a time, so every stroke starts the pan at the same place.
- Gestures and capture: `screen pinch` and other gestures, `screen gesture`, `screen record` (HEVC or H.264 `.mov`), `screen wait`, `screen shot` as PNG and at a `--width`, and stdout screenshots. OCR element selectors, `screen ocr` regions and `--fast`; OCR runs on the CPU on iOS 17 and later without a Metal device. Screen geometry is read without a screenshot, and native-resolution screenshots are redrawn before JPEG encoding.
- Input and buttons: `button siri`, `input key` digits 0–9, forward-delete and `--count`.

**Apps and device settings**
- `app settings` opens an app's page in Settings; `app permission get|grant|deny|reset` and `app reset`; launch options (`--arg`, `--env`, `--language`, `--locale`); launch and relaunch by display name, verified relaunch and millisecond `launched_at`; `app list --user`; `prefs --app` in an app container; `url open --check-changed`.
- `device appearance` and `device accessibility` read and set light or dark mode, text size and display settings.
- Lock: saved-passcode unlock and a `lock` command; lock waits use Darwin notifications.
- Logs: `log crash --summary` and `--bundle-id`, `log crashes --kind` and `--limit`, `report_type` in crash summaries, and crash cutoffs.

**Automation runs**
- `session` runs many commands in one process, one JSON line each; `batch` runs a list of steps; `status` reads the lock, front app, keyboard, overlay and prompt state in one call; `ICLI_FAILURE_ARTIFACTS` saves the error, a screenshot and the tree when a command fails.
- `lease acquire | release | status` claims the device, so other runners' icli commands get exit 75 until it ends. Each command from the holder extends the lease by its idle time (`--ttl`, default 600 seconds); it ends on `lease release` or after that long without a command.
- While a lease is held, the phone shows `icli: <owner>` just above the home indicator, so whoever holds the phone can see which runner is driving it. It is a SpringBoard tweak in the iOS packages, active after a respring. It lets touches through to the app underneath, and icli's own screenshots, OCR and `ui tree` do not see it; a wired display mirror does. It disappears on `lease release` or when the lease lapses. `icli lease indicator off` hides it, `on` brings it back.

**Testing**
- The acceptance suite installs the test apps it needs under its own lease, returns to the Home Screen and removes them afterwards, and a stopped run releases its lease.
- Checked on an iPhone 15 Pro Max running iOS 17.1.1 with Dopamine (rootless): the full acceptance suite without the reboot group passed 103 of 105 cases (`account_password` needs the mobile user's password and was not run; `touch_scroll_exact` failed before the scroll fix and then passed 10 of 10 runs). The gestures and accessibility groups passed after the scroll fix, and the full `icli flex` device suite (nine sections) passed. The tvOS package is built and checked but not run on a tvOS device.
